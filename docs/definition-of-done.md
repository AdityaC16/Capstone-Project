# Definition of Done

**DRAFT. Team to agree on Day 1.** A story is done when:

- [ ] Acceptance criteria are met
- [ ] Code is on a feature branch, reviewed and approved by 1 teammate, merged to `dev` via PR
- [ ] Unit tests are written and passing; no existing tests broken
- [ ] Pipeline is green: build, tests, Bandit, pip-audit (ZAP reviewed)
- [ ] No secrets or real data committed; input validated; SQL parameterised
- [ ] Any AI-generated code is reviewed, understood and tested
- [ ] Docs updated (README / API contract / runbook) where relevant
- [ ] Product Owner has accepted it
